# Netrunner

Unofficial Android: Netrunner rules engine, card data, and Comprehensive Rules data. Solo-maintained with coding agents.

These four repositories are one project. Consume them by release tag.

| Repository | Role | Current pin |
| --- | --- | --- |
| [netrunner-engine](https://github.com/nhoople/netrunner-engine) | Headless rules library: game state, legality, and card effects | [`v1.147.28`](https://github.com/nhoople/netrunner-engine/releases/tag/v1.147.28) |
| [netrunner-cards-data](https://github.com/nhoople/netrunner-cards-data) | JSON card definitions for the engine. Printed text is Null Signal Games reference material | [`v1.147.11`](https://github.com/nhoople/netrunner-cards-data/releases/tag/v1.147.11) |
| [netrunner-comprehensive-rules-data](https://github.com/nhoople/netrunner-comprehensive-rules-data) | Machine-readable Null Signal Games Comprehensive Rules, as JSON and JSONL | [`v26.03`](https://github.com/nhoople/netrunner-comprehensive-rules-data/releases/tag/v26.03) |
| [netrunner-game](https://github.com/nhoople/netrunner-game) | Two-seat web table for playing and verifying the engine | Pins engine `v1.147.28`, cards `v1.147.11`, and Comprehensive Rules `v26.03` |

## Known gaps and planned order

Three gaps found by the engine one-off-kind outcome-test burn-down (batch V, engine PR #366) are too large for a burn-down batch and are tracked as issues:

- **Shiro** implements superseded FFG subroutine text in its cards IR instead of the pinned NSG breach text: [cards #268](https://github.com/nhoople/netrunner-cards-data/issues/268) and [engine #368](https://github.com/nhoople/netrunner-engine/issues/368) (mid-encounter breach mechanic; design questions in the issue).
- **Rebirth's** identity switch is a logging stub: [engine #369](https://github.com/nhoople/netrunner-engine/issues/369).
- **Mandatory Seed Replacement** only rearranges ice within a server; the printed text covers all servers: [engine #370](https://github.com/nhoople/netrunner-engine/issues/370).

Agreed order from here: a few more outcome-test burn-down batches (stop after two consecutive batches with no fixes; baseline at 186), then a stale-text audit of cards-data IR `text` annotations against the pinned printed text (Shiro's family), then Mandatory Seed Replacement, then Shiro, then Rebirth last.
