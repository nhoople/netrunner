# Netrunner

Unofficial Android: Netrunner rules engine, card data, and Comprehensive Rules data. Solo-maintained with coding agents.

These four repositories are one project. Consume them by release tag.

| Repository | Role | Current pin |
| --- | --- | --- |
| [netrunner-engine](https://github.com/nhoople/netrunner-engine) | Headless rules library: game state, legality, and card effects | [`v1.147.18`](https://github.com/nhoople/netrunner-engine/releases/tag/v1.147.18) |
| [netrunner-cards-data](https://github.com/nhoople/netrunner-cards-data) | JSON card definitions for the engine. Printed text is Null Signal Games reference material | [`v1.147.10`](https://github.com/nhoople/netrunner-cards-data/releases/tag/v1.147.10) |
| [netrunner-comprehensive-rules-data](https://github.com/nhoople/netrunner-comprehensive-rules-data) | Machine-readable Null Signal Games Comprehensive Rules, as JSON and JSONL | [`v26.03`](https://github.com/nhoople/netrunner-comprehensive-rules-data/releases/tag/v26.03) |
| [netrunner-game](https://github.com/nhoople/netrunner-game) | Two-seat web table for playing and verifying the engine | Pins engine `v1.147.18`, cards `v1.147.10`, and Comprehensive Rules `v26.03` |

Engine `v1.147.18` pins cards `v1.147.10` and loads cards by side and type. Cards v1.147.8 restores uniqueness and double-sided identity faces from the source catalog; engine v1.147.12 activates the faceup face (CR 3.1.1a). Cards v1.147.9 declares `onlyDuringOwnTurn` on the 'only during your turn' cards and fixes Drago Ivanov's tag cost to the printed text; engine v1.147.13 enforces paid-ability text timing restrictions in validation, not just in offers (CR 9.5.2f). Engine v1.147.14 adds printed-outcome tests for 92 single-card IR primitives and fixes 16 that failed their card text, including a class that read the top of the deck from the wrong end. Engine v1.147.15 adds outcome tests for about 40 more kinds and fixes six more primitives, including Caprice Nisei's psi game, a stubbed-out Push Your Luck, and Snoop's never-firing trash. Engine v1.147.16 verifies all 31 dynamic-subroutine count formulas against printed text and scopes gained subroutines to their printed run or encounter (Brainstorm, Stick and Poke, Sensei). Engine v1.147.17 adds outcome tests for 24 more kinds and fixes Career Fair's choice, Mushin No Shin's new-remote install, Cyber Threat's server choice and rez cost, and rez validation for runs where the Corp cannot rez ice. Cards v1.147.10 pays Power Nap's printed flat 2 credits; engine v1.147.18 pins it. The residual text-signal queue was read for mechanics the IR might be missing entirely: one genuine hit (Power Nap); the subroutine-count and damage families were all word-mention or bespoke-kind artifacts. Instruction names lead with the Comprehensive Rules word for the procedure. The Comprehensive Rules pin is `v26.03`.
